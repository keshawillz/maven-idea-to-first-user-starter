# Design screens

Put your Claude Design screens here as PNG files, one per screen, named in flow order. For example:

- `1-home.png`
- `2-form.png`
- `3-result.png`
- `4-done.png`

Claude Code looks at these before it builds and matches them. `DESIGN.md` is the written version of the same decisions (colors, type, sizes, components). When a screen and `DESIGN.md` disagree, `DESIGN.md` wins, so fix it there.

To add a file: drag it from your computer into this folder in the file list on the left of the Codespace.

You fill this folder in Session 1. Until then it holds only this note.
